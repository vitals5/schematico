Frequently Asked Questions

Questions & Answers

Everything you need to know about Schematico, compatibility, and getting started.

Can Schematico be used completely offline without an internet connection?
Core CAD editing runs locally in the Windows, Linux, and Web apps. Desktop packages work offline; the Web app needs to be loaded first. Optional AI features require an internet connection and send your prompt, attached reference files, and required drawing context to your chosen AI provider.
How do I install Schematico on Linux?
Linux x64 downloads are available as a portable .AppImage and a Debian/Ubuntu .deb package. Make the AppImage executable before launching it, or install the Debian package with your package manager for an application-menu entry and icon. If FUSE is unavailable, the AppImage supports --appimage-extract-and-run.
Which macro formats are supported?
Schematico supports standard window macros (.ema), page macros (.ems), component data packages (.edz), and 2D enclosure outlines (.fp1). The macro manager provides high-performance access to large local directories and vendor catalogs.
Do cross-references work in the exported PDF?
Yes! The vector PDF exporter embeds native PDF hyperlinks. Clicking any contactor coil, auxiliary contact, or interruption point in standard PDF viewers (Acrobat Reader, Chrome, Apple Preview) instantly jumps to the corresponding target sheet and column.
Can Schematico be used on tablets or touch devices?
Yes. Schematico is designed as a Progressive Web App (PWA) with optimized touch gestures: smooth panning, pinch-to-zoom, generous touch targets, and an automated HUD magnifier preview while dragging components.
What license does Schematico use?
Schematico is free, open-source software distributed under the permissive MIT License. You can use it without restriction for both personal and commercial projects.
